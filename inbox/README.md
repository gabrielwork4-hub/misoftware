# Fila de produção editorial

Cada arquivo desta pasta representa um conteúdo independente. A ordem segue o cluster e o registro de slugs em `seo/briefs/slug-registry.md`.

Status usados no frontmatter:

- `draft`: texto gerado, aguardando revisão factual;
- `needs-evidence`: depende de teste, fonte ou dado adicional;
- `review`: revisão editorial/técnica em andamento;
- `approved`: pronto para migrar ao CMS.

Nenhum arquivo desta pasta deve ser publicado diretamente. Primeiro é necessário revisar fontes, exemplos, links e dados sujeitos a alteração.
